# Security policy

This package is designed to sit in authorization paths, so parser bugs that
accept malformed or ambiguous input are treated as vulnerabilities.

## Reporting a vulnerability

Please report privately through GitHub's
[private vulnerability reporting](https://github.com/zbrydon/xfcc-node/security/advisories/new).
Do not open a public issue.

Include the header (or DN) that triggers the problem, the result you expected
and the result you got. You should receive a response within 7 days.

## Supported versions

Only the latest released version receives fixes.
